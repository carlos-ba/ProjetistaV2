# Handoffs — Estado de Branches Ativas

Um arquivo por handoff em andamento, nomeado pela branch (ex:
`fix-nextjs-link-nav.md`). Conteúdo mínimo: o que está sendo feito, por qual
agente, status (em desenvolvimento / aguardando revisão / aprovado), e
qualquer contexto que o outro agente precise para revisar sem reconstruir o
raciocínio do zero.

Remover o arquivo (ou movê-lo, se quiser manter histórico) quando a branch for
mesclada em `main`.
