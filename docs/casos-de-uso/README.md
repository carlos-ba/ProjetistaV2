# Casos de Uso — Personas e Jornadas

Personas e jornadas mapeadas do ecossistema IceNexus, compartilhadas entre os
agentes. Ex: técnico (assinatura automática), revenda/montadora (atendimento
via WhatsApp), trial de 15 dias.

Um arquivo por persona ou jornada. Manter atualizado conforme decisões de
produto avançam — evita que cada agente trabalhe com uma versão diferente da
jornada do cliente.
