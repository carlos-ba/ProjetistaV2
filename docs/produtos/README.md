# Produtos — Fase de Definição

Antes de decidir qual agente desenvolve uma ferramenta nova, definir aqui:

- Público
- Problema
- Proposta de valor
- Oferta
- Plano Free e assinaturas
- Jornada de aquisição
- Estrutura da página
- Interface inicial
- Briefing técnico

de gestão que gerou esta pasta.
