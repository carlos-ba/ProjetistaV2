# Arquitetura — Decisões que Atravessam Domínios

Decisões de arquitetura relevantes para mais de um domínio do ecossistema
(SaaS + site institucional). Documentação técnica detalhada do SaaS já existe
em `docs/02_arquitetura.md` e `docs/07_decisoes_tecnicas.md` — não duplicar
aqui, referenciar.

Esta pasta é para decisões que os dois agentes (Codex e Claude) precisam
conhecer para trabalhar sem retrabalho — ex: como um novo módulo se conecta ao
SaaS existente, convenções de deploy compartilhadas, integrações entre
`site-ecosistema/` e `backend/`/`frontend/`.
